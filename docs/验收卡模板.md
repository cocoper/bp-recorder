**记录纪律（R20.5）**

- 「系统接受了提醒请求」≠「锁屏实际送达」；「分享面板打开」≠「接收端图片完整」——必须分开记录。
- 平台错误码（如 1700002）原样保留为观测，不得在没有进一步证据时归因于整机配额 / 账户 / AGC。
